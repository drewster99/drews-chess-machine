# Replay-run tracking & dashboard — standardization plan

A single, automatic pipeline for tracking DCM corpus-replay runs: capture each
per-1000-step mark into a structured store, then render data tables, graphs, and
HTML from that store. Replaces the ad-hoc scratchpad scripts (`loop_state.txt`
free-text + inline freeze/probe bash + `refresh_dashboard.py` with config
scattered across ~5 hardcoded dicts).

Status legend: ✅ done · 🔧 in progress · ⬜ not started · 🔮 future (explicitly deferred)

---

## Goals

- **Automatic.** One command per mark (`track`), one to rebuild outputs (`render`). No hand-parsing, no per-run bash.
- **Robust.** Structured store, typed columns, idempotent writes, pause/resume-aware.
- **Dual axis.** Every metric viewable **by SGD step** and **by wall-clock training time**, side by side.
- **Browsable (future).** Pick which runs to overlay on the same chart, interactively.

---

## Design decisions (settled)

| Decision | Choice | Why |
|---|---|---|
| Storage | **One CSV per run** (`data/<run>.csv`) + a **JSON run-registry** | git-diffable, greppable, loads into pandas now and a static HTML+JS page later (no server). Beats free-text (fragile regexes) and SQLite (binary, no diffs). |
| Config | `registry.json` — one block per run | Replaces the scattered `caps`/`pat`/`OFF`/`LAB`/`COLOR`/`ORDER` dicts with one source of truth. |
| Pause/resume | Per-run **`segments`** list (each fresh start / warm-start = a segment with its own log + `cumstep_base`) | `cum_step = cumstep_base + meta_step`; elapsed excludes inter-segment gaps; a BN-reset resume is recorded explicitly. |
| Elapsed time | `elapsed_train_sec` from `[REPLAY]` log timestamps, summed across completed segments + time-into-current | Pause-aware wall-clock training time; handles midnight rollover. |
| Row schema | step axis **and** time axis on every row: `cum_step, meta_step, segment, elapsed_train_sec, wallclock_iso, ms_per_step` + all metrics | Enables by-step and by-time charts from one store. |

```
documentation/
  replay-tracking-plan.md        # this file
  dashboards/
    registry.json                # run configs (label, color, cap, arch, segments)
    replay.py                    # track / migrate / render
    data/
      mini2b.csv                 # canonical per-run store
    dcm_dashboard.html           # generated output (step | time side-by-side)
    refresh_dashboard.py         # OLD — to retire
    mini2b_pElo.png              # OLD — to retire
```

## Usage

```bash
cd documentation/dashboards
python3 replay.py track mini2b     # per mark (idempotent)
python3 replay.py render           # rebuild table + charts + HTML
python3 replay.py migrate <run> --loop-state <path>   # one-time backfill
```
