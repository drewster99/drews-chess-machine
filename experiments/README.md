# Experiments — index

This is the single index of DCM experiments.

- **Every experiment gets its own folder** named `experiments/<YYYYMMDD>-<slug>/`, containing a `README.md`.
- **The README uses a fixed layout:** Question · Setup · Runs · Results · Conclusion · Caveats · Follow-ups · Audit notes.
- **Every experiment also gets one row here.** The row is the summary; the folder holds the full write-up. Keep rows short.
- Newest first.

Conventions used in the rows:

- **pElo is not on one scale across history.**
  - June 2026 self-play values (in-app probe) are on that build's scale.
  - Replay-era values (July onward) are on the current probe's scale.
  - Don't compare across the two. Each write-up says which scale it uses.
- **"wide"** means the 4,435-puzzle probe set.
- **Identity** comes from the safetensors `__metadata__`, never from filenames.
