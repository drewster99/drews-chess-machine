## Source

- **Not from database.lichess.org.** This is the *Lichess Elite Database* (<https://database.nikonoel.fr/>): Lichess games where one player is rated 2500+ and the other 2300+, with bullet excluded. It is published as one zip per month, `lichess_elite_YYYY-MM.zip`, containing `lichess_elite_YYYY-MM.pgn`.
- **Months:** 2025-05 through 2025-11 (7 files):

## Rebuild

1. **Download and concatenate:**
   ```sh
   cd ~/Downloads
   for m in 05 06 07 08 09 10 11; do curl -O https://database.nikonoel.fr/lichess_elite_2025-$m.zip && unzip lichess_elite_2025-$m.zip; done
   cat lichess_elite_2025-{05,06,07,08,09,10,11}.pgn > lichess_elite_2025-05_to_11.pgn
   ```
   The files are served as they currently exist on the site. If they were re-exported after the original download (2026-07-03), the rebuild will differ, and the body hashes below will show it.
2. **Build the importer:** `git checkout f67621f`, then do a Release build of the `DrewsChessMachine` scheme in Xcode. This importer predates the CRLF fix `18dc34f`. The fix doesn't matter for these months, which are LF: imported plus skipped accounts for every source game. It does matter for older Elite months (see [op24Gp](20260704-215145-op24Gp.md)).
3. **Import (no caps):**
   ```sh
   BIN=$(ls ~/Library/Developer/Xcode/DerivedData/DrewsChessMachine-*/Build/Products/Release/DrewsChessMachine.app/Contents/MacOS/DrewsChessMachine)
   "$BIN" --import-pgn ~/Downloads/lichess_elite_2025-05_to_11.pgn --corpus-name lichess_elite_2025-05_to_11
   ```
4. **Verify:** run `python3 experiments/corpora/shard_hashes.py <new ID>` and compare `body_sha256` and the counts with the table below. Whole-file hashes never match, because the header carries the freshly minted corpus ID (see the [w3aA5b manifest](20260624-192615-w3aA5b.md#verify-a-rebuild)). To use the result under the old ID, pass its path to `--replay-corpus` or rename the directory.
