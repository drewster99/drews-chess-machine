- **The whole-file SHA-256 will not match.** Each shard's 256-byte front header holds the corpus ID, source ID and creation time, and its 64-byte trailer holds the seal time and a SHA over the header. Compare **`body_sha256`** instead: the SHA-256 of the bytes between header and trailer, which is the game records only.
- Run `python3 experiments/corpora/shard_hashes.py <new corpus ID or dir>` and diff its table against the one below. All 46 `body_sha256` values and the game and ply counts must match.
